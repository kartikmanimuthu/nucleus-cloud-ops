How should "Sync Now" work?

Pick the interaction pattern for triggering per-account or full sync

A

Dropdown Button

Clicking "Sync Now" opens a dropdown with "Sync All Accounts" at the top, then each account listed below. One click to trigger.

↻ Sync Now ▾
↻ Sync All Accounts
STX-DATA-AP (767…)
STX-PROD-US (123…)

Pros

  • Fewest clicks
  • Always visible

Cons

  • Long list with many accounts
B

Modal / Dialog

Clicking "Sync Now" opens a dialog with checkboxes for each account. User selects one, many, or all, then confirms.

Select accounts to sync
☑ All Accounts
☑ STX-DATA-AP (767…)
☐ STX-PROD-US (123…)
Sync Selected
Cancel

Pros

  • Multi-select support
  • Scales to many accounts

Cons

  • Extra click to confirm
C

Split Button

Left side triggers "Sync All" immediately. Right chevron opens a dropdown to pick a specific account.

↻ Sync All
▾
STX-DATA-AP (767…)
STX-PROD-US (123…)

Pros

  • One-click for common case
  • Clean separation

Cons

  • Slightly unfamiliar pattern
  • No multi-select
