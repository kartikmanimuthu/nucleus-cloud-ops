Text-to-SQL Agent — API Route & Streaming UX

How the Ask AI API route changes and what the user sees during each agent step

API Route Changes

Before (RAG)
POST /api/ask-ai

1. Generate embedding (Titan v2)
2. pgvector search OR listResources
3. Build RAG system prompt
4. streamText() → plain text stream
5. X-AI-Sources header with resources

Response: text/plain stream
After (Text-to-SQL Agent)
POST /api/ask-ai

1. Create/resume LangGraph thread
2. Invoke text-to-sql graph
3. Stream agent events via SSE
4. Each node emits typed events
5. Final answer streams as text chunks

Response: text/event-stream (SSE)

SSE Event Protocol

What the User Sees

Ask AI Dialog — Step-by-Step Streaming
How many EC2 instances are running per region?
🤖
✓ Schema loaded
✓ SQL generated
✓ Query executed (42 rows)
✓ Results verified
SQL QUERY ▼ 
SELECT region, COUNT(*) as count
FROM inventory_resources
WHERE tenant_id = $1
  AND resource_type = 'ec2_instances'
  AND status = 'running'
GROUP BY region
ORDER BY count DESC
