# Quick Task 260403-u2f: fix missing tenantId in validateAccount updateAccount call

**Date:** 2026-04-03
**Status:** Ready for execution

## Root Cause

`POST /api/accounts/[accountId]/validate/route.ts` calls `AccountService.validateAccount(accountId)` without passing `tenantId`. `validateAccount` then calls `updateAccount(accountId, ..., tenantId)` where `tenantId` is `undefined`, causing Prisma to throw `PrismaClientValidationError` because the composite unique key `tenantId_accountId` requires both fields.

## Plan

### Task 1: Fix validate route to pass tenantId

**Files:** `web-ui/app/api/accounts/[accountId]/validate/route.ts`

**Action:**
1. Import `getSessionTenantId` from `@/lib/auth-session`
2. Call `getSessionTenantId()` before invoking `AccountService.validateAccount`
3. Pass `tenantId` as second argument to `AccountService.validateAccount(accountId, tenantId)`

**Verify:** `POST /api/accounts/:id/validate` no longer returns 500; Prisma query includes tenantId in the where clause.

**Done:** Route passes tenantId; error log gone.
