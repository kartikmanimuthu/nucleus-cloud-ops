# Quick Task 260408-32q: Fix discovery scanner stuck — not scanning all AWS account resources

## Root Cause

`invokeService()` in `scanner.ts` has an infinite pagination loop bug. The code reads the next-page token from multiple response fields (`NextToken`, `Marker`, `NextPageToken`, `nextToken`) but always sends it back as `NextToken`:

```typescript
const paginatedParams = { ...params, ...(nextToken ? { NextToken: nextToken } : {}) };
```

IAM APIs (`list_roles`, `list_users`) use `Marker` as both input and output parameter. When IAM returns `Marker`, the code picks it up but sends it back as `NextToken` — which IAM ignores. IAM returns the same first page with `IsTruncated: true`, creating an infinite loop that hangs the scanner.

## Fix

Track which response field contained the pagination token and send it back with the matching input parameter name.
