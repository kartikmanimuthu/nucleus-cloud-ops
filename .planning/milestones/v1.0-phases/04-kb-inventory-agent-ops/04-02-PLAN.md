**postgres.ts** — `KnowledgeBasePostgresRepository implements IKnowledgeBaseRepository`. Use `getPrismaClient()` from `@/lib/db/pg-config`. Every query scoped by `tenantId` (per D-17). For `updateDataSourceCount`/`updateVectorCount`, use Prisma `update` with `increment`:
```typescript
await getPrismaClient().knowledgeBase.update({
  where: { id: kbId, tenantId },  // Note: use findFirst to get by kbId then update by id, since kbId maps to the application id field
  data: { dataSourceCount: { increment: delta }, updatedAt: new Date() },
});
```
Actually, since the Prisma model uses `id` as PK (cuid), but the application uses `kbId` (UUID from service), the postgres repo should:
- `listKnowledgeBases`: `findMany({ where: { tenantId }, orderBy: { createdAt: 'desc' } })`
- `getKnowledgeBase`: `findFirst({ where: { id: kbId, tenantId } })` — the `id` field in Prisma IS the kbId
- `createKnowledgeBase`: `create({ data: { tenantId, name, description, createdBy, status: 'active', vectorCount: 0, dataSourceCount: 0 } })`
- `updateDataSourceCount`: `update({ where: { id: kbId }, data: { dataSourceCount: { increment: delta } } })` — verify tenantId matches first
- `updateVectorCount`: same pattern with `vectorCount: { increment: delta }`
- Transform Prisma result to `KnowledgeBase` type (createdAt/updatedAt to ISO strings)
