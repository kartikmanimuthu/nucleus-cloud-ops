## Page Contracts

### `/signup` — Create Account

Layout: identical to `/login` — `min-h-screen bg-background flex items-center justify-center p-4`, centered card `w-full max-w-sm bg-card border border-border rounded-xl shadow-sm p-8`.

Structure (top to bottom):
1. Logo row — `w-8 h-8 bg-primary rounded-lg` + Zap icon + "Nucleus Ops" `font-bold text-lg`
2. Heading block — "Create your account" (`text-2xl font-bold`) + "Sign up to get started" (`text-sm text-muted-foreground mt-1`)
3. Tabs — `grid w-full grid-cols-2 mb-6` — "Email & Password" | "SSO"
4. Credentials tab — email field + password field + confirm password field + submit button
5. SSO tab — description text + "Sign up with SSO" button
6. Footer — "Already have an account? [Sign in]" (`text-sm text-muted-foreground`, link `text-primary hover:underline`)

Field error display: `text-xs text-destructive mt-1` with `role="alert"` and `aria-describedby` wired to input.

Server error display: `text-sm text-destructive` block above submit button with `role="alert"`.

Submit button: `w-full h-11`, disabled + `Loader2 animate-spin` during submission.

### `/create-org` — Create Organization

Layout: same centered card pattern, `w-full max-w-sm`.

Structure (top to bottom):
1. Logo row — same as signup
2. Heading block — "Create your organization" (`text-2xl font-bold`) + "Set up your workspace to get started" (`text-sm text-muted-foreground mt-1`)
3. Org name field — standard Input, label "Organization name"
4. Slug field — Input with trailing icon slot; on blur: debounced availability check (300ms); states: idle / checking (Loader2) / available (CheckCircle2 `text-primary`) / taken (XCircle `text-destructive`)
5. Slug hint — `text-xs text-muted-foreground` below field: "Lowercase letters, numbers, and hyphens only. 3–50 characters."
6. Submit button — "Create organization", `w-full h-11`, disabled during slug check or submission

No back/cancel link — user must complete org creation to access the app.

## Interaction Contracts

### Slug availability check

- Trigger: `onBlur` on slug input
- Debounce: 300ms
- API: `GET /api/tenants/check-slug?slug={value}`
- States:
  - Idle: no trailing icon
  - Checking: `Loader2 animate-spin w-4 h-4 text-muted-foreground` in input trailing slot
  - Available: `CheckCircle2 w-4 h-4 text-primary` + caption "Slug is available" (`text-xs text-primary`)
  - Taken: `XCircle w-4 h-4 text-destructive` + error "This slug is already taken. Try another." (`text-xs text-destructive role="alert"`)
  - Invalid format: client-side zod error before API call — "Slug must be 3–50 lowercase letters, numbers, or hyphens"
- Submit button disabled while check is in-flight or slug is taken

### Form submission loading

- All inputs: `disabled={isLoading}`
- Button: replace label with `<Loader2 className="mr-2 h-4 w-4 animate-spin" /> {verb}ing...`
- Pattern: "Creating account..." / "Creating organization..."

### Session loading skeleton

- While `useSession()` status === "loading": render card with 3–4 `<Skeleton>` blocks matching field heights
- Same pattern as login page

### Login page footer link (additive change)

Add to existing `/login` page footer: "Don't have an account? [Sign up]" — same `text-sm text-muted-foreground` + `text-primary hover:underline` pattern.
