# Phase 22 Plan 02: Wire Executor into Entrypoint + Job Registration

## Objective

Wire the `JobExecutor` (from 22-01) into `workers/src/index.ts` and update both job `register()` functions to accept and use the executor — replacing raw `console.log` with structured logger and routing `boss.work()` callbacks through `executor.execute()`.

## Context

- `workers/src/executor/` — JobExecutor interface, VerticalExecutor, HorizontalExecutor, createExecutor factory (from 22-01)
- `workers/src/lib/logger.ts` — createLogger(service) structured logger (from 22-01)
- `workers/src/index.ts` — entrypoint, currently uses raw console.log
- `workers/src/jobs/scheduler/index.ts` — register(boss) with inline boss.work callback
- `workers/src/jobs/kb-sync/index.ts` — register(boss) with inline boss.work callback

## Tasks

### Task 1: Wire executor into entrypoint

**Type:** auto

Update `workers/src/index.ts`:
- Import `createExecutor` from `./executor/index.js`
- Import `createLogger` from `./lib/logger.js`
- Create `executor = createExecutor(process.env.WORKER_ARCH ?? 'vertical')`
- Pass executor to each `register()` call
- Replace all `console.log/error` with structured logger

**Done criteria:** index.ts imports createExecutor, creates executor, passes it to register calls, uses log.* not console.*

### Task 2: Update job register() functions

**Type:** auto

Update `workers/src/jobs/scheduler/index.ts`:
- Add `executor: JobExecutor` second parameter
- Call `executor.registerHandler?.('scheduler-scan', handler)` with the scan logic
- In `boss.work()` callback: call `executor.execute('scheduler-scan', job.data)`
- Replace `console.log/error` with `createLogger('scheduler')`

Update `workers/src/jobs/kb-sync/index.ts`:
- Add `executor: JobExecutor` second parameter
- Call `executor.registerHandler?.('kb-sync', handler)` with the sync logic (including switch)
- In `boss.work()` callback: call `executor.execute('kb-sync', job.data)` (error handling stays in boss.work)
- Replace `console.log/error` with `createLogger('kb-sync')`

Update existing tests to pass mock executor:
- `workers/src/jobs/scheduler/index.test.ts` — add mockExecutor, assert registerHandler called
- `workers/src/jobs/kb-sync/index.test.ts` — add mockExecutor, assert registerHandler called

**Done criteria:** Both register() accept executor, boss.work callbacks call executor.execute(), tests pass
