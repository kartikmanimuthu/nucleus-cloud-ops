## Interaction Contracts

### Invite Member Dialog

Trigger: "Invite Member" button (top-right of Members page).

```
Dialog
  DialogHeader
    DialogTitle: "Invite a team member"
    DialogDescription: "They'll receive an email with instructions to join your organization."
  DialogContent
    Form
      FormField: Email
        FormLabel: "Email address"
        Input type="email" placeholder="colleague@company.com"
        FormMessage (zod error)
      FormField: Role
        FormLabel: "Role"
        Select
          SelectItem for each role at or below current user's level
        FormMessage (zod error)
  DialogFooter
    Button variant="outline" onClick=close: "Cancel"
    Button type="submit" (primary): "Send Invitation"
      loading state: "Sending..." with spinner, button disabled
```

Validation (zod):
- email: z.string().email("Enter a valid email address")
- role: z.string().min(1, "Select a role")

Submit success: dialog closes, invitations table refreshes, no toast (table update is sufficient feedback).
Submit error: inline error below form fields using FormMessage, dialog stays open.

### Resend Action

Location: Actions column of Pending Invitations table.
Button: variant="outline" size="sm", label "Resend".
Cooldown: 60 seconds after resend — button disabled with tooltip "Resend available in Xs" (countdown). Cooldown tracked in component state, not persisted.
Success: button briefly shows "Sent" text for 2 seconds, then reverts to "Resend".

### Revoke Action

Location: Actions column of Pending Invitations table.
Button: variant="ghost" size="sm" className="text-destructive hover:text-destructive", label "Revoke".
Triggers AlertDialog before executing.

AlertDialog copy:
- Title: "Revoke invitation?"
- Description: "The invitation sent to [email] will be cancelled. They won't be able to use it to join your organization."
- Cancel: "Keep invitation"
- Confirm: variant="destructive", label "Revoke invitation"

On confirm: row removed from table optimistically, API call executes, error restores row if failed.

### Empty States

Members table empty (no members besides self):
```
Card
  CardHeader: CardTitle "No other members yet"
  CardContent: p.text-muted-foreground.text-sm
    "Invite your team to start collaborating. They'll receive an email to set up their account."
```

Pending invitations table empty:
```
Card
  CardHeader: CardTitle "No pending invitations"
  CardContent: p.text-muted-foreground.text-sm
    "All invitations have been accepted, or none have been sent yet."
```

### Loading State

Both tables: `p.text-muted-foreground.text-sm "Loading..."` (matches roles/page.tsx pattern). No skeleton loaders in this phase.

### Error State

API fetch failure: `p.text-sm.text-destructive` inline above the affected table.
Copy: "Failed to load [members / invitations]. Refresh the page to try again."

Invite API failure (non-form error, e.g. Cognito limit): `p.text-sm.text-destructive` inside DialogFooter above action buttons.
Copy: "Could not send invitation. [error message from API]."
