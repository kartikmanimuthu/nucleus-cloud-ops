<!-- Established schema patterns from Phase 2 (02-01-SUMMARY.md) -->

Prisma model conventions:
- No FK relations to Tenant table (plain string tenantId for zero-downtime)
- @@unique([tenantId, entityId]) — per-tenant uniqueness
- @@index([tenantId]) — multi-tenant list queries
- @@index([tenantId, active]) — active/inactive filters
- CHECK constraints for enum-like fields added via ALTER TABLE in migration SQL (not Prisma-native)
- Model names: PascalCase → table names: snake_case via @@map("table_name")

Existing DynamoDB field shapes (from web-ui/lib/types.ts and schedule-service.ts):
- Schedule: { name, starttime, endtime, timezone, active, days: string[], description?, tenantId, accountId, resources: [{id, type, name?, arn?, clusterArn?}], createdAt, updatedAt, createdBy, updatedBy }
- ScheduleExecution: { executionId, tenantId, accountId, scheduleId, executionTime, status: 'pending'|'running'|'success'|'failed'|'partial', resourcesStarted, resourcesStopped, resourcesFailed, duration?, errorMessage?, details?, schedule_metadata? }
- AuditLog: { id, type, timestamp, eventType, action, user, userType, resource, resourceType, resourceId, status, severity, details, metadata?, ipAddress?, correlationId?, executionId?, region?, accountId?, source, expireAt: number (epoch TTL) }

Targeted resources (SCHEDULE#id PK / RESOURCE#arn SK pattern from CLAUDE.md):

Model 1: Schedule
```prisma
model Schedule {
  id             String   @id @default(cuid())
  tenantId       String
  scheduleId     String   // Application-level UUID (e.g., sched-*)
  accountId      String
  name           String
  description    String?
  starttime      String   // HH:MM 24h format
  endtime        String   // HH:MM 24h format
  timezone       String   @default("UTC")
  days           String[] // ["Mon","Tue",...] array
  active         Boolean  @default(true)
  resources      Json     @default("[]") // Array of {id,type,name?,arn?,clusterArn?}
  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt
  createdBy      String   @default("system")
  updatedBy      String   @default("system")

  @@unique([tenantId, scheduleId])
  @@index([tenantId])
  @@index([tenantId, active])
  @@index([tenantId, accountId])
  @@map("schedules")
}
```

Model 2: ScheduleExecution
```prisma
model ScheduleExecution {
  id                String   @id @default(cuid())
  tenantId          String
  executionId       String   // Application-level ID (e.g., exec-*)
  scheduleId        String
  accountId         String
  status            String   // pending|running|success|failed|partial
  executionTime     DateTime
  resourcesStarted  Int      @default(0)
  resourcesStopped  Int      @default(0)
  resourcesFailed   Int      @default(0)
  duration          Int?     // seconds
  errorMessage      String?
  details           Json?    // free-form execution details
  scheduleMetadata  Json?    // grouped per-resource-type execution records
  expiresAt         DateTime // TTL replacement — set to now + 90 days on insert

  @@unique([tenantId, executionId])
  @@index([tenantId])
  @@index([tenantId, scheduleId])
  @@index([tenantId, status])
  @@index([expiresAt]) // for cleanup-expired.ts
  @@map("schedule_executions")
}
```

Model 3: TargetedResource
```prisma
model TargetedResource {
  id           String   @id @default(cuid())
  tenantId     String
  scheduleId   String
  resourceArn  String
  resourceType String   // ec2|ecs|rds|asg|docdb
  resourceId   String
  name         String?
  clusterArn   String?  // ECS only
  createdAt    DateTime @default(now())

  @@unique([tenantId, scheduleId, resourceArn])
  @@index([tenantId, scheduleId])
  @@map("targeted_resources")
}
```

Model 4: AuditLog
```prisma
model AuditLog {
  id           String   @id @default(cuid())
  tenantId     String
  logId        String   // Application-level ID (e.g., log-*)
  timestamp    DateTime @default(now())
  eventType    String
  action       String
  user         String   @default("system")
  userType     String   @default("system") // system|user|admin|external
  resource     String?
  resourceType String?
  resourceId   String?
  status       String   @default("info") // success|error|warning|info
  severity     String   @default("info") // low|medium|high|critical|info
  details      String?
  metadata     Json?
  ipAddress    String?
  userAgent    String?
  sessionId    String?
  correlationId String?
  executionId  String?
  region       String?
  accountId    String?
  duration     Int?
  errorCode    String?
  source       String   @default("system") // web-ui|lambda|system|api
  expiresAt    DateTime // TTL replacement — set to now + 30 days (audit retention)

  @@unique([tenantId, logId])
  @@index([tenantId])
  @@index([tenantId, eventType])
  @@index([tenantId, user])
  @@index([tenantId, timestamp])
  @@index([expiresAt]) // for cleanup-expired.ts
  @@map("audit_logs")
}
```

No FK relations to any other model (same zero-downtime pattern as accounts). No CHECK constraints in schema (add via ALTER TABLE in migration SQL, same pattern as user_tenant_roles.role).
