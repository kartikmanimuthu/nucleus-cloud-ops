    **3. IAM policy for ECS dispatch (per D-09, Claude's discretion):**
    Add a new RolePolicy to `workersTaskRole` granting `ecs:RunTask` and `ecs:DescribeTasks`. Place it after the existing workers IAM policies (after line 1575, before the workers task def).

    ```typescript
    new aws.iam.RolePolicy("workers-ecs-dispatch-policy", {
        role: workersTaskRole.id,
        policy: ephemeralWorkerTaskDef.arn.apply(taskDefArn =>
            JSON.stringify({
                Version: "2012-10-17",
                Statement: [
                    {
                        Effect: "Allow",
                        Action: ["ecs:RunTask"],
                        Resource: [taskDefArn],
                    },
                    {
                        Effect: "Allow",
                        Action: ["ecs:DescribeTasks"],
                        Resource: ["*"],
                        Condition: {
                            ArnEquals: {

    });
    ```
