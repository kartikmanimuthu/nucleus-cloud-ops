Create `infra/build-images.sh` (chmod +x) with these steps:
1. `#!/usr/bin/env bash` with `set -euo pipefail`
2. Variables: `ECR_REPO_NAME="nucleus-cloud-ops-web-ui"`, `AWS_REGION` from env or default `us-east-1`, `AWS_PROFILE` from env or default `PLATFORM-ADMIN`
3. Get AWS account ID: `ACCOUNT_ID=$(aws sts get-caller-identity --profile "$AWS_PROFILE" --query Account --output text)`
4. Build ECR URI: `ECR_URI="${ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com/${ECR_REPO_NAME}"`
5. Create ECR repo if not exists: `aws ecr describe-repositories --repository-names "$ECR_REPO_NAME" --region "$AWS_REGION" --profile "$AWS_PROFILE" 2>/dev/null || aws ecr create-repository --repository-name "$ECR_REPO_NAME" --region "$AWS_REGION" --profile "$AWS_PROFILE"`
6. Docker login: `aws ecr get-login-password --region "$AWS_REGION" --profile "$AWS_PROFILE" | docker login --username AWS --password-stdin "${ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com"`
7. Build: `docker build -f web-ui/Dockerfile.ecs --platform linux/arm64 -t "${ECR_URI}:latest" web-ui/`
8. Push: `docker push "${ECR_URI}:latest"`
9. Print: `echo "Image URI: ${ECR_URI}:latest"` and `echo "Set in Pulumi: cd infra/compute && pulumi config set webUiImageUri ${ECR_URI}:latest"`
