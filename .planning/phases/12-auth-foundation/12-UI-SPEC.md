## Layout Contract

Login page (`/login`) is a full-page centered layout — no sidebar, no nav.

Primary visual anchor: "Welcome back" heading — largest text element on the page, first content after the logo row.

```
min-h-screen bg-background flex items-center justify-center p-4
  └── w-full max-w-sm
        └── bg-card border border-border rounded-xl shadow-sm p-8
              ├── Logo row (Zap icon + "Nucleus Ops" wordmark, gap-2)
              ├── Heading block ("Welcome back" + subtext)
              ├── Tabs (Email & Password | SSO)
              │     ├── Tab: Email & Password
              │     │     ├── Email input + label
              │     │     ├── Password input + label
              │     │     ├── "Forgot password?" link (right-aligned, below password)
              │     │     ├── Inline error zone (hidden until error)
              │     │     └── "Sign in" button (full width)
              │     └── Tab: SSO
              │           ├── Descriptive text (one line)
              │           ├── Inline error zone (hidden until error)
              │           └── "Sign in with SSO" button (full width)
              └── "Need help? Contact Support" footer link
```

Default tab: "Email & Password" (source: D-02, CONTEXT.md).

## Interaction States

### Credentials Tab

| State | Trigger | Visual |
|-------|---------|--------|
| Default | Page load | Empty inputs, no errors |
| Loading | Submit clicked | Button shows `<Loader2 animate-spin>` + "Signing in..." text; inputs disabled |
| Field error | Zod validation fail | Red text (text-destructive, text-xs) below the offending field; input border turns destructive |
| Auth error | Wrong credentials | Error message below form fields (not inside an input); inputs re-enabled |
| Lockout error | 5 failed attempts | Lockout message replaces auth error; "Sign in" button disabled until TTL expires |

### SSO Tab

| State | Trigger | Visual |
|-------|---------|--------|
| Default | Tab selected | Descriptive text visible, button enabled |
| Loading | Button clicked | Button shows spinner + "Signing in..." text |
| Provider error | Cognito failure | Error message below button |

### Page Load Skeleton (Claude's Discretion)

Show `<Skeleton>` for the card content area during session check (`useSession` status === "loading"). Replace with actual form once status resolves. Prevents layout shift.

## Accessibility Contract

- All inputs must have associated `<Label>` with `htmlFor` matching input `id`
- Error messages must use `role="alert"` or be associated via `aria-describedby` on the input
- Tab focus order: Email → Password → Forgot password → Sign in button → Tab switcher
- Minimum touch target for buttons: 44px height (use `h-11` on Button)
- "Forgot password?" link must be keyboard-reachable and have visible focus ring
