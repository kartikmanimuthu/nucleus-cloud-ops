   ```prisma
   // === NextAuth Prisma Adapter Models ===
   // Per D-05: database sessions (not JWT) for suspension enforcement
   // @@map to auth_* tables to avoid collision with existing Account model

   model AuthUser {
     id             String        @id @default(cuid())
     email          String        @unique
     emailVerified  DateTime?
     name           String?
     image          String?
     passwordHash   String?       // null for Cognito-only users
     isSuperAdmin   Boolean       @default(false)
     failedAttempts Int           @default(0)
     lockedUntil    DateTime?
     createdAt      DateTime      @default(now())
     updatedAt      DateTime      @updatedAt

     accounts       AuthAccount[]
     sessions       AuthSession[]

     @@map("auth_users")
   }

   model AuthAccount {
     id                String  @id @default(cuid())
     userId            String
     type              String
     provider          String
     providerAccountId String
     refresh_token     String? @db.Text
     access_token      String? @db.Text
     expires_at        Int?
     token_type        String?
     scope             String?
     id_token          String? @db.Text
     session_state     String?

     user AuthUser @relation(fields: [userId], references: [id], onDelete: Cascade)

     @@unique([provider, providerAccountId])
     @@map("auth_accounts")
   }

   model AuthSession {
     id           String   @id @default(cuid())
     sessionToken String   @unique
     userId       String
     expires      DateTime

     user AuthUser @relation(fields: [userId], references: [id], onDelete: Cascade)

     @@map("auth_sessions")
   }

   model VerificationToken {
     identifier String
     token      String   @unique
     expires    DateTime

     @@unique([identifier, token])
     @@map("verification_tokens")
   }
   ```

   - `id: "credentials"`, `name: "Credentials"`
   - `credentials: { email: { label: "Email", type: "email" }, password: { label: "Password", type: "password" } }`
   - `authorize` function that:
     a. Validates email and password are non-empty strings
     b. Queries `prisma.authUser.findUnique({ where: { email } })` (use the model name from schema)
     c. Returns `null` if user not found or `passwordHash` is null (Cognito-only user)
     d. Checks `lockedUntil` — if `lockedUntil > new Date()`, throw error `"Account locked. Try again in X minutes."` (per D-11: 15 min lockout)
     e. Compares password with `bcrypt.compare(password, user.passwordHash)` using bcryptjs
     f. On wrong password: increments `failedAttempts` via `prisma.authUser.update`. If `failedAttempts >= 5`, sets `lockedUntil = new Date(Date.now() + 15 * 60 * 1000)` (per D-11)
     g. On success: resets `failedAttempts` to 0 and `lockedUntil` to null, returns `{ id: user.id, email: user.email, isSuperAdmin: user.isSuperAdmin, failedAttempts: 0, lockedUntil: null }`
5. `callbacks.session` must:
   - Receive `{ session, user }` (database strategy gives `user` not `token`)
   - Query `prisma.userTenantRole.findFirst({ where: { userId: user.id } })` to get tenantId and role
   - Set `session.user = { id: user.id, email: user.email, tenantId: utr?.tenantId ?? null, role: utr?.role ?? null, isSuperAdmin: (user as any).isSuperAdmin ?? false }`
   - Return session
6. Keep `pages: { signIn: '/login', error: '/login' }`.
7. Keep the existing `redirect` callback unchanged.
8. Import `@/lib/auth-types` at the top for type augmentation side effects.

Create a thin wrapper or use Prisma's `$extends` if needed, OR simply pass the prisma client directly since `@auth/prisma-adapter` v2 supports custom model names via the adapter options. Check the adapter docs — if it doesn't support custom names, create a proxy object:

For the Prisma client import: use `import { PrismaClient } from '@prisma/client'` and instantiate a singleton (or import from an existing db utility if one exists — check `web-ui/lib/db/` for a shared client).
