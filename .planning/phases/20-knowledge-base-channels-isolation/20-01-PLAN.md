    **IMPORTANT — DataSource service method signatures:**
    The DynamoDB `KnowledgeBaseService` data source methods (`listDataSources`, `getDataSource`, `createDataSource`, `updateDataSource`, `deleteDataSource`) do NOT accept `tenantId`. Do NOT pass tenantId to these calls — it will cause TypeScript errors. Tenant isolation for data source operations is achieved via the pre-flight KB ownership check: verify the parent kbId belongs to the tenant (using `KnowledgeBaseService.getKnowledgeBase(kbId, tenantId)` which DOES accept tenantId), then call data source methods with their existing signatures (scoped by kbId partition key). This is sufficient because data sources are children of a KB, and the KB is already verified to belong to the tenant.

    - DELETE already calls `getSessionTenantId()` and `listDataSources(kbId)`. Add pre-flight: after getting tenantId, call `KnowledgeBaseService.getKnowledgeBase(kbId, tenantId)` — if null, return 403 `{ success: false, error: 'Forbidden' }`. Keep `listDataSources(kbId)` and `deleteDataSource(kbId, ds.id)` calls as-is (no tenantId param — these methods don't accept it).

      // 5. Filter vectors to tenant scope
      let filtered: typeof rawVectors;
      if (knowledgeBaseId) {
