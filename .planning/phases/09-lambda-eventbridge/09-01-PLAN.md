<action>
Create `infra/build-lambdas.sh` (chmod +x) that builds all 3 TypeScript Lambdas:

1. **Scheduler** (`lambda/scheduler/`):
   ```bash
   cd lambda/scheduler
   npx esbuild src/index.ts --bundle --platform=node --target=node20 --format=cjs --outfile=dist/index.js --external:@aws-sdk/*
   cd dist && zip -r ../lambda.zip index.js && cd ..
   ```

2. **VectorProcessor** (`lambda/vector_processor/`):
   ```bash
   cd lambda/vector_processor
   npx esbuild src/index.ts --bundle --platform=node --target=node20 --format=cjs --outfile=dist/index.js \
     --external:@aws-sdk/client-s3 --external:@aws-sdk/client-bedrock-runtime \
     --external:@aws-sdk/client-dynamodb --external:@aws-sdk/lib-dynamodb
   cd dist && zip -r ../lambda.zip index.js && cd ..
   ```
   Note: Do NOT externalize `@aws-sdk/client-s3vectors` — it must be bundled (may not be in Lambda runtime).

3. **KBSyncProcessor** (`lambda/kb_sync_processor/`):
   ```bash
   cd lambda/kb_sync_processor
   npm ci --omit=dev
   npx esbuild src/index.ts --bundle --platform=node --target=node20 --format=cjs --outfile=dist/index.js \
     --external:@aws-sdk/client-s3 --external:@aws-sdk/client-bedrock-runtime \
     --external:@aws-sdk/client-dynamodb --external:@aws-sdk/lib-dynamodb
   # Copy node_modules for pdf-parse and @aws-sdk/client-s3vectors into dist/
   mkdir -p dist/node_modules
   cp -r node_modules/pdf-parse dist/node_modules/
   cp -r node_modules/@aws-sdk/client-s3vectors dist/node_modules/
   cd dist && zip -r ../lambda.zip . && cd ..
   ```
   KBSyncProcessor needs `pdf-parse` and `@aws-sdk/client-s3vectors` as bundled node_modules (matching CDK's `nodeModules` config).

Script should:
- Use `set -euo pipefail`
- Accept an optional `--lambda=<name>` arg to build just one (default: all)
- Print build status for each Lambda
- Use `SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"` and `PROJECT_ROOT="$(dirname "$SCRIPT_DIR")"` for paths
- Exit non-zero on any build failure
</action>

```typescript
const snsTopic = new aws.sns.Topic("scheduler-sns-topic", {
    name: "nucleus-cloud-ops-sns-topic",
});

// Email subscriptions from config (comma-separated, skip empty)
const emails = subscriptionEmails.split(",").map(e => e.trim()).filter(e => e.length > 0);
emails.forEach((email, i) => {
    new aws.sns.TopicSubscription(`sns-email-sub-${i}`, {
        topic: snsTopic.arn,
        protocol: "email",
        endpoint: email,
    });
});
```

**Scheduler Lambda IAM Role** (`nucleus-cloud-ops-lambda-role`):
- AssumeRolePolicy: `lambda.amazonaws.com`
- Attach `AWSLambdaBasicExecutionRole` managed policy
- Inline policy with 3 statements:
  1. DynamoDB: `GetItem, Scan, Query, PutItem, UpdateItem, DeleteItem, BatchWriteItem` on `appTable.arn`, `${appTable.arn}/index/*`, `auditTable.arn`, `${auditTable.arn}/index/*`
  2. STS: `sts:AssumeRole` on `arn:aws:iam::*:role/${crossAccountRoleName}` and `arn:aws:iam::*:role/NucleusAccess-*`
  3. SNS: `sns:Publish` on `snsTopic.arn`

**Scheduler Lambda Function** (`nucleus-cloud-ops-function`):
```typescript
const schedulerLambda = new aws.lambda.Function("scheduler-lambda", {
    functionName: "nucleus-cloud-ops-function",
    role: schedulerLambdaRole.arn,
    runtime: "nodejs20.x",
    architectures: ["arm64"],
    handler: "index.handler",
    code: new pulumi.asset.FileArchive("../../lambda/scheduler/lambda.zip"),
    timeout: 900,
    memorySize: 1024,
    environment: {
        variables: {
            APP_TABLE_NAME: appTable.name,
            AUDIT_TABLE_NAME: auditTable.name,
            CROSS_ACCOUNT_ROLE_ARN: schedulerLambdaRole.arn,
            SCHEDULER_TAG: "cost-optimization-scheduler",
            SNS_TOPIC_ARN: snsTopic.arn,
            HUB_ACCOUNT_ID: accountId,
            NEXT_PUBLIC_HUB_ACCOUNT_ID: accountId,
        },
    },
});
```
Note: `code` uses `FileArchive` pointing to the zip built by `build-lambdas.sh`. Path is relative from `infra/compute/` to `lambda/scheduler/lambda.zip`.

**EventBridge Rule** (`nucleus-cloud-ops-rule`):
```typescript
const schedulerRule = new aws.cloudwatch.EventRule("scheduler-trigger-rule", {
    name: "nucleus-cloud-ops-rule",
    scheduleExpression: "cron(0,30 * * * ? *)",
});

new aws.cloudwatch.EventTarget("scheduler-trigger-target", {
    rule: schedulerRule.name,
    arn: schedulerLambda.arn,
});

new aws.lambda.Permission("scheduler-eventbridge-permission", {
    action: "lambda:InvokeFunction",
    function: schedulerLambda.name,
    principal: "events.amazonaws.com",
    sourceArn: schedulerRule.arn,
});
```
