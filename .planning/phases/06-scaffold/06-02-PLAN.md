  <action>
Run the following commands in sequence:

1. Install dependencies in both projects:
```bash
cd infra/networking && npm install
cd infra/compute && npm install
```

2. Initialize Pulumi stacks with KMS secrets provider (requires bootstrap.sh to have been run first):
```bash
cd infra/networking && pulumi stack init prod --secrets-provider="awskms://alias/pulumi-secrets"
cd infra/compute && pulumi stack init prod --secrets-provider="awskms://alias/pulumi-secrets"
```

If `pulumi stack init` fails with "stack already exists", that's fine — it means bootstrap.sh already created it. Run `pulumi stack select prod` instead.

If `pulumi stack init` fails with a backend connection error, the bootstrap script hasn't been run yet. Stop and inform the user they need to run `infra/bootstrap/bootstrap.sh` first.

3. Verify the stacks are using KMS (not passphrase):
```bash
cd infra/networking && pulumi stack --show-secrets-provider
cd infra/compute && pulumi stack --show-secrets-provider
```
Expected output should contain `awskms://` — NOT `passphrase`.
