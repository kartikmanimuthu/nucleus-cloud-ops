The awsx subnet Name tag format differs from expected. Fix the filter in index.ts to use CIDR matching instead:
```typescript
const databaseSubnetIds = vpc.subnets.apply(subnets =>
    subnets
        .filter(s => s.cidrBlock.apply(c =>
            c?.startsWith("10.0.10.") || c?.startsWith("10.0.11.")))
        .map(s => s.id)
);

const intraSubnetIds = vpc.subnets.apply(subnets =>
    subnets
        .filter(s => s.cidrBlock.apply(c =>
            c?.startsWith("10.0.12.")))
        .map(s => s.id)
);
```
Then run `pulumi up --stack prod --yes` again to apply the fix (no resource replacement needed — only the output values change).
