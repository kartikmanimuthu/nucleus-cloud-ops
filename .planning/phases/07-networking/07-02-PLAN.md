**If TypeScript errors occur:**

Common fixes:
- `vpc.subnets` type issue: `vpc.subnets` returns `Output<SubnetV2[]>` — use `.apply()` correctly
- `vpc.vpc.cidrBlock` not found: use `vpc.vpcId` and a separate `aws.ec2.getVpcOutput({ id: vpc.vpcId }).cidrBlock` instead
- Duplicate export identifier: remove the intermediate `vpcCidrOutput` variable; export `vpcCidr` directly as `vpc.vpc.cidrBlock`
- `endpointRouteTableIds` nested Output: ensure `pulumi.all(routeTableOutputs).apply(...)` is used to flatten

Fix any TypeScript errors in index.ts, then re-run preview until it succeeds.

**If subnet Name tag format is wrong:**

After seeing the planned subnet Name tags in preview output, update the filter in index.ts:
```typescript
// If awsx uses "nucleus-vpc-database-0" format:
.filter(s => s.tags.apply(t => (t?.["Name"] ?? "").includes("-database-")))

// If awsx uses "nucleus-vpc-Isolated-0" format (no spec name):
// Must filter by CIDR instead:
.filter(s => s.cidrBlock.apply(c => c?.startsWith("10.0.10.") || c?.startsWith("10.0.11.")))
```

Re-run preview after any fix to confirm databaseSubnetIds and intraSubnetIds will each have exactly 2 elements.
