## AWS Accounts

### Adding an Account

Go to **AWS Accounts** → **Integrate Account**.

![AWS Accounts](/screenshots/accounts.png)

Provide:
- **Account ID** — 12-digit AWS account ID
- **Role ARN** — IAM role Nucleus Ops will assume (e.g. `arn:aws:iam::123456789012:role/NucleusAccess-XXXXXXXXXX`)
- **Region** — Primary region to scan (e.g. `ap-south-1`)

### IAM Role Setup

Create a role in the target account with this trust policy:

```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Principal": {
      "AWS": "arn:aws:iam::NUCLEUS_ACCOUNT_ID:role/NucleusOpsExecutionRole"
    },
    "Action": "sts:AssumeRole"
  }]
}
```

Attach the `NucleusOpsPolicy` with permissions for EC2, RDS, ECS describe/start/stop actions.

### Account Status

Each account has two independent states:
- **Account Status** — `Active` or `Inactive` (controls whether schedules run)
- **Connection** — `Connected`, `Unknown` (IAM role reachability)

Use **Validate** to test the IAM role connection. Use **Activate/Deactivate** to control scheduling.

## Cost Scheduler

### Schedule Configuration

![Cost Scheduler](/screenshots/schedules.png)

| Field | Description |
|-------|-------------|
| Name | Friendly name for the schedule |
| Account | Target AWS account |
| Resources | EC2 instances, RDS clusters, or ECS services |
| Start Time | Time to start resources (e.g. `09:00:00`) |
| Stop Time | Time to stop resources (e.g. `19:00:00`) |
| Timezone | IANA timezone (e.g. `Asia/Kolkata`) |
| Days | Mon–Fri, weekends, or custom day selection |

### Cron Expressions

Nucleus Ops supports standard cron syntax:

```
# Start at 9am Mon-Fri
0 9 * * 1-5

# Stop at 7pm Mon-Fri
0 19 * * 1-5
```

## AI Ops Agent

### Overview

![AI Ops](/screenshots/ai-ops.png)

The AI Ops agent uses a **Plan → Execute → Reflect → Revise** loop powered by Claude Sonnet 4.6 via AWS Bedrock.

**Controls:**
- **Model** — Claude Sonnet 4.6 (default)
- **Mode** — Fast (ReAct) or Planning
- **Auto-approve tools** — Execute actions without confirmation
- **Select Accounts** — Scope the agent to specific accounts
- **Agent Skills** — Pre-built skill prompts for common tasks
- **Select Tools** — Enable/disable specific tools (9 built-in + MCP)

### Bedrock Configuration

Ensure your execution role has:

```json
{
  "Effect": "Allow",
  "Action": ["bedrock:InvokeModel", "bedrock:InvokeModelWithResponseStream"],
  "Resource": "arn:aws:bedrock:*::foundation-model/anthropic.claude-sonnet-4-6*"
}
```

### MCP Servers

Add custom MCP servers under **Channels** → **MCP Servers** to extend the agent's capabilities. 16 MCP servers are supported out of the box. For connecting Atlassian's Jira/Confluence MCP server — including headless auth for Docker/ECS deployments — see the dedicated [Jira / Atlassian Integration](/docs/jira-integration) guide.
